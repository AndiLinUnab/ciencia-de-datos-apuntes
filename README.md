# Apuntes de Ciencia de Datos

Repositorio con los apuntes, ejercicios y notebooks de la asignatura de Ciencia de Datos, elaborados durante mi formación en Ingeniería de Sistemas en la Universidad Autónoma de Bucaramanga (UNAB).

El objetivo es reunir en un solo lugar los conceptos, técnicas y herramientas vistas en el curso, de modo que sirvan como material de consulta y repaso.

## Temas

Los apuntes cubren, en términos generales, los siguientes temas:

- **Introducción a la ciencia de datos:** conceptos básicos, ciclo de vida de un proyecto de datos y metodologías como CRISP-DM.
- **Python para análisis de datos:** manejo de datos con NumPy y Pandas, y visualización con Matplotlib y Seaborn.
- **Limpieza y preparación de datos:** tratamiento de valores nulos, detección de valores atípicos, transformación y escalado de variables.
- **Análisis exploratorio de datos (EDA):** estadísticas descriptivas, distribuciones, correlaciones y visualizaciones.
- **Estadística:** probabilidad, distribuciones, inferencia estadística y pruebas de hipótesis.
- **Aprendizaje automático:** regresión, clasificación, clustering, validación cruzada y métricas de evaluación con Scikit-learn.
- **Bases de datos y SQL:** consultas para la extracción y manipulación de datos.

## Tecnologías utilizadas

- Python 3
- Jupyter Notebook
- NumPy

- Matplotlib y Seaborn
- Scikit-learn
- SQL

## Cómo usar este repositorio

1. Clonar el repositorio:

```bash
   git clone https://github.com/AndiLinUnab/ciencia-de-datos-apuntes.git
   cd ciencia-de-datos-apuntes
```

2. Crear y activar un entorno virtual (opcional, pero recomendado):

```bash
   python -m venv venv
   source venv/bin/activate    # En Windows: venv\Scripts\activate
```

3. Instalar las librerías necesarias:

```bash
   pip install numpy pandas matplotlib seaborn scikit-learn jupyter
```

4. Abrir los notebooks:

```bash
   jupyter notebook
```
